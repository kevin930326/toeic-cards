# 後續產品驗證

目前以個人備考與公開作品集為主，尚未建立收費、追蹤分析或學習成效保證。

若考慮收費，先邀請願意參與的使用者連續試用，記錄每週是否繼續使用、放棄原因、最常使用的流程，以及是否願意為具體功能付費。經使用者同意才收集資料，不預設加入全站追蹤。

成本要區分：Gemini 生成加第二輪題目覆核的請求量、重試量、Firestore 交易讀寫與帳本容量、維護及人工題目審核成本。以實際帳單與使用量估算，不以免費額度假設商業模式一定成立。

排程分類、打卡與答題數都是使用紀錄，無法直接推導多益分數或長期記憶改善。若宣稱成效，需要另設前後測、保留測驗與適當比較，而非把「21 天間隔」當成證明。
