# 第 28 步：導覽文字垂直對齊

## 目標

使用者發現「複習」比探索、測驗、單字庫、統計偏下，要讓主導覽的文字對齊。

## 做法

將主導覽連結統一為 inline-flex、垂直置中及相同行高，並讓導覽列置中子項；下拉選單內容仍維持原本的區塊排版。更新樣式引用版本。

## 遇到的問題與解法

- **原因**：複習連結位於額外的 flex 容器中，混合數字徽章與選單按鈕，文字行框對齊方式與其他連結不同。
- **解法**：不再依賴各自的行框，所有主導覽連結都改用同一套 inline-flex 垂直置中（見上方做法）。

## 測試結果

使用 `webapp-testing` 的 Playwright 瀏覽器流程，`test_nav_alignment.py` 以文字 Range 量測垂直中心。修正前差距約 1.8px；修正後在1280／768／390／375／320px、徽章隱藏或1／16／1000時，差距均為0px。確認沒有橫向溢出，下拉選單仍能開啟、Escape關閉並返回焦點。

這是版面修正，沒有新增技術決策或資料變更。
