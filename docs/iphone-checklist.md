# iPhone 真機驗證清單

狀態：待驗證。開發環境沒有可操作的 iPhone；以下不能由桌面模擬結果取代。

請記錄裝置、iOS 版本、日期、網站提交版本，分別在 Safari 分頁與加入主畫面 App 執行：

- 首次教學點「加入單字」、切批次分頁不自動喚起鍵盤；手動輸入後提示縮小，收鍵盤後位置恢復。
- 鍵盤開啟時捲動、切橫直向、收放 Safari 工具列，光圈貼合目標、下一步與結束可按。
- 管理單字集、查字等額外視窗開啟時暫停教學；關閉恢復同一步。
- 空白複習與已有卡片時，教學與按鈕不重疊；中央左右滑卡與螢幕邊緣系統返回操作分工。
- 點卡翻面不誤查字；查字模式、查字視窗、編輯與刪除取消後焦點合理。
- 登入、登出、A/B 切換及訪客確認。正式帳號由使用者自行驗證，勿建立測試帳號污染正式資料。
- 更新提示出現後關閉所有本網站分頁／主畫面 App，再重開；離線重開可用同一完整版本。
- VoiceOver 能讀取目前卡面與可見欄位，隱藏卡面不重複朗讀。

每項記錄「通過／失敗／未測」，失敗附操作順序與截圖，勿在截圖留下 Email 或金鑰。
